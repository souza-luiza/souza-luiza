## 🕹️ Projetos em Destaque

### 📚 Livramente

> **LivraMente** é uma rede social literária voltada para leitores brasileiros, desenvolvida na UC de Engenharia de Software com metodologia ágil **Scrum**.  
> A plataforma permite criação de comunidades, readlists e interação entre usuários.
> O sistema inclui autenticação com JWT e cookies HttpOnly, além de integração com a Google Books API (mais de 100 livros disponíveis).

🛠️ **Tecnologias utilizadas**: NestJS, Next.js, MongoDB  
🎨 **Categoria**: Aplicação Web / Rede Social  
🔗 [GitHub](https://github.com/souza-luiza/LivraMente)

### 🎮 Firehose: Kerana Origins

> **Firehose: Kerana Origins** é um jogo 2D onde uma **onça-pintada** embarca em uma jornada por diferentes fases e missões, com o objetivo de encontrar e derrotar o responsável por um incêndio criminoso no seu vilarejo.  
> O projeto inclui implementação da lógica de fases, sistema de missões e movimentação de personagens.

🛠️ **Tecnologias utilizadas**: Unity, C#  
🎨 **Gênero**: Drama-aventura 2D  
🔗 [GitHub](https://github.com/souza-luiza/Kerana-Firehose)

### 🎒 UP

> **UP** é uma plataforma de apoio aos estudos desenvolvida com metodologia **TDD (Test-Driven Development).**    
> Implementação de autenticação com JWT e refresh tokens, além de geração de cronogramas e flashcards. 
> O sistema possui testes unitários, de integração, E2E e testes de mutação no backend.

🛠️ **Tecnologias utilizadas**: Java Spring Boot, Next.js, PostgreSQL  
🎨 **Categoria**: Aplicação Web / Plataforma Educacional     
🔗 [GitHub](https://github.com/souza-luiza/UP)
